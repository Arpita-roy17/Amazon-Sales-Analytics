# Amazon Sales Analytics – Data Engineering Project

## Project Overview
An end-to-end data engineering and analytics project built using Amazon sales data. The project transforms raw sales data into structured datasets and presents meaningful business insights through an interactive Power BI dashboard.

## Tech Stack
- Python
- Apache Spark (PySpark)
- Databricks
- Power BI
- SQL

## Project Architecture
The project follows a Medallion Architecture:

- **Bronze Layer:** Ingests and stores raw Amazon sales data.
- **Silver Layer:** Cleans, transforms and prepares the data.
- **Gold Layer:** Creates aggregated datasets for business analysis.
- **Visualization:** Power BI dashboard for interactive sales analysis.

## Dashboard Insights
- Overall sales and order performance
- Daily sales trends
- Category-wise sales contribution
- Fulfilment analysis
- State-wise sales performance
- Top-performing SKUs
- Product and category insights
